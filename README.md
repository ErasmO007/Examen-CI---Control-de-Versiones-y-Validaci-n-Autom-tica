
## Nombre del proyecto
 Examen CI - Control de Versiones y Validación Automática

## Objetivo
Organizar el código de un equipo de programadores mediante un repositorio Git,
evitando el intercambio manual de archivos y la pérdida de cambios, y sentar las
bases para validar automáticamente cada cambio (integración continua) y reducir
la entrega de versiones con errores.
